# Beaver Mock Contest

A practice site for the Beaver Computing Challenge (Grade 7/8, with Grade 9/10 as a stretch).
It runs fully in the browser; scores are saved only in your own browser.

- `docs/` is the site. Open `docs/index.html`, or serve the folder with GitHub Pages.
- `tools/` holds the one-off scripts used to build the question files (run from the repo root).
